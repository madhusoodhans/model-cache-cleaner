# Google AI Edge Gallery

```json
{
  "tool": "Google AI Edge Gallery",
  "homepage": "https://github.com/google-ai-edge/gallery",
  "verified": "2026-10-24",
  "locations": [
    {
      "kind": "models",
      "macos": ["~/Library/Application Support/com.google.AIEdgeGallery"],
      "after_delete": "On-device models, re-downloaded from inside the app."
    }
  ]
}
```

## What it stores

- **`com.google.AIEdgeGallery`:** on-device models (Gemma and others) downloaded to try in the app. It was 12 GB on the machine this was verified on.

## Safe to delete

- The whole folder, if the user no longer uses the app.

## How to clean

1. Delete models from inside the app, or
2. Quit the app and remove the folder.
